# Use Case 1 — Media Optimization

This example demonstrates the **SBF Index — Biofilm Formation** workflow for evaluating biofilm formation under different media conditions.

### Files

- `data/OD570.xlsx` — OD570 Tecan i-control export.
- `data/OD600.xlsx` — OD600 Tecan i-control export.
- `plate/sbf_plate_template.json` — plate map used for the analysis.
- `output/BiofilmQ-HT_Output.pdf` — captured BiofilmQ-HT results output.
- `output/BiofilmQ-HT_Report.pdf` — generated publication-ready report.

The plate map includes replicate wells for each strain/condition under the 25% LB and 100% LB media conditions, together with media-matched blank wells.

The input data files are the original experimental files; only their filenames have been normalized for repository organization. No experimental values have been changed.
