SBF Index — Biofilm Formation

Quantify biofilm biomass (crystal violet, OD570) normalized to growth (OD600). Classifies strains/conditions as non/weak/moderate/strong biofilm formers.

🧪

Antibiofilm Activity — % Inhibition

Compare each strain/condition against an untreated Positive ctrl using OD570 only, to calculate % biofilm inhibition. No OD600 file needed.
