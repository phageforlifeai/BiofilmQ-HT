# BiofilmQ-HT Release Notes

## Release 1.0.0

This package is intended for publication/repository distribution of the supplied BiofilmQ-HT browser utility.

- `BiofilmQ-HT.html` — original supplied application file
- `README.md` — repository overview and quick-start information

- `CITATION.cff` — GitHub citation metadata

The application file was copied without modification. Repository documentation does not alter the application.
