# Use Case 2 — Antibiofilm Activity

This example demonstrates the **Antibiofilm Activity — % Inhibition** workflow using OD570 measurements and a positive-control condition.

### Files

- `data/OD570.xlsx` — original Tecan i-control OD570 export used for the analysis.
- `plate/antibiofilm_plate_template.json` — plate map used for the analysis.
- `output/BiofilmQ-HT_Output.pdf` — captured BiofilmQ-HT results output.
- `output/BiofilmQ-HT_Report.pdf` — generated publication-ready report.

The supplied plate map contains the positive-control, treatment/combination conditions, and blank wells used in this example.

The original labeled OD570 workbook is retained. The separate unlabeled copy of the workbook is not included because it does not provide additional information for reproducing the analysis.
