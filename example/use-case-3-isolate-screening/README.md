# BiofilmQ-HT Example Use Cases

This directory contains three example datasets demonstrating the two BiofilmQ-HT analysis workflows across representative laboratory use cases.

## Use cases

1. **Media optimization** — Specific Biofilm Formation (SBF) analysis using OD570 normalized to OD600 across different media conditions.
2. **Antibiofilm activity** — percentage biofilm inhibition analysis using OD570 measurements and a positive control.
3. **Screening for biofilm-forming capabilities of isolates** — SBF analysis of multiple isolates using replicate measurements under a single default medium.

Each use case contains the input data, plate-layout template, and generated outputs used for the demonstration. The original experimental input files are retained without modification; filenames may be normalized only for repository organization.
